# Object-Oriented Programming 面向对象

## 技术概要

本项目原则是基于组合和继承的 OOP
所有数据的读取校验和写入都依靠相应的类实现

## 对象

### CHRONOLOGY 历法

- 是唯一的最上级对象
- 这类对象有一个唯一的 id

### CONFIG 配置

- 这个对象与世界观设计无关，只是对软件的设置

### DOCUMENT 文档

- 这类对象是各类文档
- 这类对象有一个唯一的 id

### ELEMENT 元素

- 这类对象不会单独存在，一定是其他对象的某个键值对的值

### ENTITY 实体

- 这类对象是构建起世界观的核心对象，每个 ENTITY 都有各自的一个或多个演示形式
- 这类对象有一个唯一的 id

### ENUM 枚举类型对象

- 这类对象不会单独存在，一定是其他对象的某个键值对的值

### EVENT 事件

- 这类对象是世界观被构建后，演示内容的其中一个核心对象，大事年表、时间轴等，都演示事件
- 这类对象有一个唯一的 id

### LOG 日志

- 这类对象与世界观设计无关，只是用于调试

### RELATIONSHIP 关系

- 这类对象描述了两个 ENTITY 的关系，也是演示内容的一个核心对象，关系星图等，都演示关系
- 这类对象有一个唯一的 id，而且还有一个目标 id，关系是单向的、不可传递的
