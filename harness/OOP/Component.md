# Component 页面组件

## Macro 宏

- tx — 文字，显示

bt 表示按钮

- bt-bk — 返回符号按钮 — 弹栈
- bt-ed — 按钮 `编辑`
- bt-dl — 按钮 `删除`
- bt-dl-sg — 删除符号按钮
- bt-bc — 按钮 `批量管理`
- bt-ca — 按钮 `取消` — 取消本次行为，弹栈
- bt-sv — 按钮 `💾 保存` — 保存数据，弹栈
- bt-rs — 按钮 `重置`
- bt-to-ed — 按钮 `去修改`
- bt-cf — 按钮 `确定`
- bt-sft — 单选按钮，切换于

inp 表示输入框

- inp-tx — 文字输入框
- inp-nm — 数字输入框

slc 表示下拉选择框

- slc-cg — 历法下拉选择框，选项显示 name 的值
- slc-wd — 世界下拉选择框，选项显示 name 的值
