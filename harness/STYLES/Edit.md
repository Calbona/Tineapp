# Edit 编辑页

> 文档和 CSS 仅供参考，不要完全照抄

## 内容

- 新建和修改时进入实例编辑页
- 各种实例编辑页视觉风格要统一
- 各种实例编辑卡片视觉风格要统一

## 通用结构

编辑页共享以下组件：

1. **标题行**：`back-btn`（返回）+ `page-title`（页面标题，含对象名）
2. **元信息表单**：包含普通元信息、**分段值列表卡片**、**属性列表卡片**和**描述文档**
3. **其他文档列表卡片**
4. **提交区**：`submit-btn`

### 列表页

- 列表 + 新增入口 + 每项删除按钮
- 列表为空时显示空态占位（`form-placeholder` 风格）
- 编辑页与新建页复用同一套实例编辑卡片，仅标题与提交行为区分

### 实例页

- 所有实例编辑卡片视觉统一且协调
- 引用的对象选择框显示该对象的 "name"，不显示 Id 或无意义的编号
